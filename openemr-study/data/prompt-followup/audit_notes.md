# Model score audit notes

This is a targeted AI audit of the model judge's explanations and sampled raw reviews. It is not independent human verification. The [blinded packet](../../evidence/study-results.zip) is still awaiting human review.

- **CVE-2026-24898 (`item_07`), stronger prompt:** all three reviews block on the unvalidated `callback_key` after removal of the login gate. They do not clearly state that the echoed login response exposes a token. The Fable judge counted the correct broken-auth class and location as Caught. A human should decide whether the missing token-disclosure consequence makes any run Partial under the original rubric. [Review 1](../../cases/CVE-2026-24898.md), [judge 1](../../cases/CVE-2026-24898.md).
- **CVE-2026-25476 (`item_10`), stronger prompt:** all three reviews state that request-controlled `skip_timeout_reset` bypasses session expiration. Runs 1 and 3 partly describe the effect as skipping the expiration update rather than the validation check. The finding and block recommendation are explicit, but the mechanism wording needs review. [Review 1](../../cases/CVE-2026-25476.md), [judge 1](../../cases/CVE-2026-25476.md).
- **CVE-2026-33913 (`item_16`), stronger prompt:** run 2 identifies `LIBXML_XINCLUDE` and XML inclusion attacks but does not clearly state local-file read; the other two are explicit. Its majority Caught result would survive a single downgrade. [Review 2](../../cases/CVE-2026-33913.md), [judge 2](../../cases/CVE-2026-33913.md).
- **CVE-2018-15152 (`item_19`), stronger prompt:** run 1 hedges that the fabricated session values *could* bypass checks elsewhere. Runs 2 and 3 assert the authentication bypass at the correct session assignments, so its majority Caught result would survive a single downgrade. [Review 1](../../cases/CVE-2018-15152.md), [judge 1](../../cases/CVE-2018-15152.md).
- **CVE-2026-25746 (`item_11`), new generic:** run 3 names SQL injection at the correct ORDER BY line but explains it imprecisely through deprecated escaping and `patient_id`. Run 2 is a clear catch; a human downgrade of run 3 would move the new generic case from Caught to Partial. [Review 3](../../cases/CVE-2026-25746.md), [judge 3](../../cases/CVE-2026-25746.md).
- **CVE-2026-32238 (`item_13`), new generic:** run 2 leads with a SQL injection label but also identifies unescaped values in shell command construction and recommends `escapeshellarg()`. Runs 1 and 3 explicitly identify shell command execution, so the case remains Caught if run 2 changes. [Review 2](../../cases/CVE-2026-32238.md), [judge 2](../../cases/CVE-2026-32238.md).
- **Controls:** the model judge's 60 summary lines were checked against their detailed finding lines. Its false classifications include repeated claims that a safe allowlist or bound query is injectable, that a fixed session timeout remains bypassable, and that a short diff proves missing access control or logging elsewhere. The distinction between false security alarms and speculative questions still requires human review. [Per-review controls](benign_scores.csv), [packet](../../evidence/study-results.zip).

No score was changed in this audit. The published tables remain model-judged and provisional.
