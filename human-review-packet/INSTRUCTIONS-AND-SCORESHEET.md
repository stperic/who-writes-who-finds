Thank you for participating in this blind code-review exercise!

## Instructions for Reviewers
1. **Time budget:** Please spend **no more than 5 minutes per diff** (30 minutes total across the 6 diffs).
2. **No external lookups:** Review only the diff text shown in `diffs/packet_01.diff` through `diffs/packet_06.diff`. Do not search GitHub, NVD, or the web.
3. **Task (identical to the prompt given to the AI models):**
   > *You are reviewing a pull request diff before it is merged. Review the code and report any issues you would raise as a reviewer: correctness, security, reliability, or maintainability. For each issue, give the location, the problem, and the severity. If you find no issues, say so.*
4. **Do not open `ANSWER-KEY-DO-NOT-OPEN-FIRST.md`** until after you have recorded your notes below.
